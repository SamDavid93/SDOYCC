The application serves its fonts locally. No connection to Google Fonts is required.

- Manrope variable: `https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf`
- DM Mono Regular and Medium: `https://github.com/google/fonts/tree/main/ofl/dmmono`

Downloaded unchanged from the official Google Fonts repository on 2026-10-14.
Both families use the SIL Open Font License 1.1; the original license texts are
included as `manrope-OFL.txt` and `dmmono-OFL.txt`.
